DAN CELL — CATÁLOGO ONLINE

Arquivos prontos para Vercel.

Para funcionar com cadastro sincronizado:
1. Crie/publique o projeto na Vercel.
2. No projeto, crie um Vercel Blob Store público e conecte ao projeto.
   A Vercel cria automaticamente BLOB_READ_WRITE_TOKEN.
3. Adicione a variável de ambiente ADMIN_PIN com o PIN que desejar.
   Se não configurar, o padrão do código é 2026.
4. Faça um novo deploy.

Depois disso, qualquer produto salvo na Área do lojista fica disponível para todos os clientes.
